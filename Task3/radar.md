<br><h2>Обоснование ключевых изменений</h2>

1. Переход с SQL Server 2008 → PostgreSQL:
Почему: Устаревшая СУБД не поддерживает современные аналитические нагрузки.
Преимущества: Горизонтальное масштабирование, встроенная поддержка JSON.

2. Замена Power BI → Qlik Sense:
Почему: Qlik Sense лучше подходит для ассоциативной аналитики и самообслуживания.
Преимущества: Скорость работы с большими данными, AI-подсказки.

3. Внедрение Apache NiFi и Kafka вместо Apache Camel:
Почему: Event-driven архитектура для реального времени.
Преимущества:
3.1. Масштабируемость и производительность: Kafka обеспечивает высокопроизводительный event-стриминг с горизонтальным масштабированием, а NiFi — удобный GUI для сложных ETL-процессов, что критично для больших объемов данных (сотни ТБ в DWH).
3.2. Разделение ответственности: Kafka выступает как надежный транспорт для реального времени, а NiFi заменяет ESB-логику Camel (трансформации, маршрутизацию, ФЛК), упрощая поддержку и развитие доменов.
Итог: Переход снижает нагрузку на Legacy DWH, ускоряет delivery данных и упрощает добавление новых источников.

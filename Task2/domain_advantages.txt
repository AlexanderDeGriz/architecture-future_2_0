Разделение системы на медицинский, финансовый и аналитический домены дает компании «Будущее 2.0» следующие выгоды:

1. Изолированная ответственность (можно настроить доступы гранулярно к каждому домену, врачи не поучают доступ к фининформации, а бухгалтерия к диагнозам)
2. Соответствие регуляторным требованиям (медицинские и финансовые данные хранятся раздельно)
3. Гибкость технологического стека (оптимальные для домена технологии: MongoDB для медицинских неструктурированных данных, PostgreSQL для финансовых транзакций)
4. Ускорение разработки (параллельная работа команд, независимые доработки, микросервисная архитектура)
5. Горизонтальное масштабирование для конкретного домена
7. Экономия ресурсов (тяжелые аналитические запросы выполняются в Qlik Sense, а не в основной БД)
8. Оптимизация затрат: Для каждого домена можно выбрать облачное решение с подходящим тарифом (например, мед. данные — холодное хранение в S3).
